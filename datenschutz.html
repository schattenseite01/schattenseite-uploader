Datenschutzerklärung – Schattenseite Uploader

Stand: Oktober 2026

Wer nutzt das Werkzeug?

Der „Schattenseite Uploader“ ist ein privates Werkzeug. Es wird ausschließlich vom Betreiber des YouTube-Kanals „Schattenseite“ für den eigenen Kanal verwendet. Andere Personen können sich nicht anmelden und es werden keine Daten Dritter verarbeitet.

Welche Daten werden verarbeitet?

Das Werkzeug verwendet die YouTube Data API v3 nur, um selbst erstellte Videos auf den eigenen Kanal hochzuladen und deren Veröffentlichungszeitpunkt festzulegen. Dazu wird über Google OAuth ein Zugriffstoken für den eigenen Kanal angefordert (Berechtigung: Videos hochladen und verwalten).

Wo werden die Daten gespeichert?

Das Zugriffstoken wird ausschließlich lokal auf dem Rechner des Betreibers gespeichert (in der lokalen Automatisierungssoftware n8n). Es wird an keinen Server außer an Google übertragen.

Weitergabe

Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Google-Richtlinien

Die Nutzung der YouTube-API unterliegt den YouTube-Nutzungsbedingungen und der Google-Datenschutzerklärung.
